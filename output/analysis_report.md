## Overview

A Spring Boot REST API for the Sakila database, covering catalog, customer, location, payment, rental, staff, store, and auth workflows.

- Manages film and actor data, including their relationships and detail views.
- Manages customers and their related payment and rental history views.
- Manages addresses and cities as part of the location data model.
- Manages payment records and payment detail views.
- Manages rental lifecycle operations, including return processing.
- Manages staff records and staff detail views.
- Manages stores and store-staff relationships.
- Provides a login endpoint that issues JWT-based authentication tokens.
- Exposes sales report views by category and by store.
- Wraps many read models in HATEOAS response representations.
- Generates OpenAPI and Postman artifacts from REST Docs tests.
- Exposes actuator and Prometheus monitoring endpoints.

**Architecture.** The application is organized as a layered Spring Boot service. HTTP requests enter controller classes under the configured `/api/v1` context path, then flow into domain services and repository/query layers for persistence and custom projections. Many read operations are mapped into DTOs and then wrapped in Spring HATEOAS representation models before being returned. Cross-cutting infrastructure is configured separately for security, JWT, JPA, Redis, Querydsl/Blaze-Persistence, logging, and documentation generation.

**Technologies.** Spring Boot, Spring Web, Spring Security, Spring Data JPA, Spring Data Redis, Spring HATEOAS, Spring Validation, Spring Boot Actuator, Querydsl, Blaze-Persistence, MapStruct, Lombok, jjwt, MySQL, Micrometer Prometheus, Spring REST Docs, Asciidoctor, Kotlin DSL Gradle
